Key points:

Browser API automatically:
Chooses and rotates proxy IPs for you

Session persistence with Browser API
Force a specific country/region → use the -country flag or Proxy.setLocation as described here:
Location targeting for Browser API
So:

If you’re fine with automatic rotation and best-effort unblocking → nothing to set up.

You’re in the right place—“America” just won’t appear in the list because we use country names and 2‑letter codes, not “America” as a label.

For the United States, look for:

Country name: “United States of America (the)”
Country code: us
You have two options, both valid:

Option 1 – Set US as a default country in the UI
In the Create Proxy flow for Datacenter / ISP / Residential shared proxies:

In Default countries, open the dropdown.
Scroll or type to search for “United States of America (the)”.
Select it and finish creating the proxy.
Then all requests will try to use US IPs by default (unless you override via username flags).

Option 2 – Leave defaults empty and target US in the username
You can leave Default countries empty and control geolocation per request using the -country-us flag in the username.

Example (with your account id already filled in):

sh

curl "http://target.site" \
  --proxy brd.superproxy.io:33335 \
  --proxy-user brd-customer-hl_14bd7443-zone-<proxy_name>-country-us:<proxy_password>
Replace <proxy_name> and <proxy_password> with the values from your proxy’s Overview tab.

This will always send the request from the US, even if no default country is set.
